

# House Rental Management System

A modern, responsive  house rental management system built with React.js, Tailwind CSS, and Context API.

## Features

- **Multi-role System**: Tenant, Property Owner, and Administrator dashboards
- **Property Management**: Add, edit, delete, and view properties
- **Advanced Search & Filtering**: Filter by location, price, bedrooms, bathrooms, and more
- **Favorites System**: Save and manage favorite properties
- **Rental Requests**: Submit and manage rental requests
- **Notifications**: Real-time notifications for updates
- **Dark/Light Mode**: Toggle between themes
- **Responsive Design**: Mobile-first approach
- **Mock Charts**: Visual analytics with Recharts

## Tech Stack

- React 18
- React Router v6
- Tailwind CSS
- Context API
- React Icons
- Recharts

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`
4. Build for production: `npm run build`

## Demo Users

Use the user menu in the navbar to switch between roles:
- **Tenant**: Browse properties, submit rental requests, manage favorites
- **Owner**: Manage properties, view rental requests
- **Admin**: Approve properties, manage users, view analytics
